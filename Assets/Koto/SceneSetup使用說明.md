# 場景設定控制器

基準取自 `Assets/Scenes/fight test map.unity`，目前只保存玩家、敵人、鏡頭與攻擊回饋。設定保存於 `Assets/Koto/Prefabs/SceneSetup`，控制器腳本為 `Assets/Koto/SceneSetupController.cs`。

## 在新場景使用

1. 從 `Assets/Koto/Prefabs/SceneSetup` 拖入 `player.prefab`，放到玩家出生位置。
2. 按關卡需求拖入 `enemy-sheep.prefab`（羊怪）或 `enemy-flower.prefab`（花怪），可放多隻。花怪已包含本體，不必再另外放 `moster3-2`。
3. 拖入同資料夾的 `SceneSetupController.prefab`。也可在空物件掛上 `SceneSetupController` 腳本，會自動載入已保存的基準。
4. 確認玩家根物件的 Tag 是 `Player`，敵人根物件是 `Enemy`，主鏡頭是 `MainCamera`。提供的角色預置體已設定 Tag。
5. 保存場景後播放。

控制器會自動處理：

- 補齊玩家與這兩種敵人缺少的元件，使用保存的數值與本地引用。
- 連接玩家移動鏡頭、鏡頭跟隨、敵人偵測玩家與玩家光源。
- 連接攻擊回饋使用的鏡頭。
- 場景缺少主鏡頭或攻擊回饋物件時，從保存的預置體建立；已有對應物件時使用現有物件。
- 首次配置鏡頭時，套用基準的投影、角度與相對玩家偏移。

玩家與敵人的數量、位置由關卡決定；控制器不會自行生成玩家或敵人。先放控制器、之後再放玩家也可以，玩家加入後會完成鏡頭定位。每個場景放一個控制器、一個 `Player` 與一個 `MainCamera`。

UI（能量條、死亡畫面、物品格）、後處理 Volume 與 EventSystem 暫不保存、不自動建立或綁定；若場景需要這些物件，請在該場景另外設定。

更新後配置時，會清理控制器底下舊版自動建立的上述額外物件；場景原本的物件僅移除工具連結標記，物件本身保留。

## 保存之後的修改

### 新增敵人種類（例如 moster1 small）

1. 停止播放，將 `Assets/animation/moster1/small/moster1 small.prefab` 放入場景，調整敵人的腳本與數值，確認根物件 Tag 是 `Enemy`。若尚未配置小怪腳本，可先執行 `Koto → 分裂小球 → 設定預置體與目前場景`。
2. 選擇場景中的控制器，點 Inspector 右上角鎖頭鎖定面板。
3. 在 Hierarchy 選擇調整好的小怪，再於鎖定的控制器面板按「新增選取敵人的設定」。
4. 工具會在 `Assets/Koto/Prefabs/SceneSetup` 建立獨立敵人 Prefab，並將其登記到控制器 Prefab。保存場景；之後可將新保存的敵人 Prefab 拖入其他場景使用。

新增功能只保存選取的新敵人；已登記的敵人請用「保存目前場景設定到預置體」更新。同一種敵人只需登記一次，腳本、動畫、材質與攻擊點會一起保存。

**直接修改預置體：** 在 Project 中雙擊本資料夾的角色或鏡頭預置體，於 Prefab Mode 調整原本的各個元件並保存。之後拖入新場景就使用修改後的值。不要刪除自動加入的 `SceneSetupActor` 元件，它保存跨場景引用的重綁規則。

**從場景保存：** 停止播放，選擇控制器，按「保存目前場景設定到預置體」。會把此場景中找到的角色、鏡頭與攻擊回饋設定保存回控制器列出的預置體，並更新鏡頭相對玩家的偏移。沒有出現在目前場景的敵人種類不會被改寫。

若同一種敵人有多隻：先選擇控制器並鎖定 Inspector，再點選 Hierarchy 中要作為範本的敵人，最後按保存。不同實例的數值可能不同，因此不會隨機挑一隻覆寫範本。若有多種敵人都各有多個實例，請分別在各自的 Prefab Mode 修改。

保存範圍內的跨物件引用（例如敵人的玩家、玩家的鏡頭）會保存成可重新尋找的連結。範圍外的場景引用只會在保存的副本中清空，場景原本手動設定的引用會保留。動畫、材質、聲音等資產引用及角色內部骨架、攻擊點則直接保存在預置體。

## 控制器按鈕

- **搜尋 Tag 並補齊／綁定**：重新搜尋與補齊缺少的引用。已配置物件的有效設定會保留。
- **新增選取敵人的設定**：將選取且尚未登記的 Enemy 保存為新的設定 Prefab，加入控制器清單。
- **將已保存設定重新套用到場景**：重新套用保存的數值與腳本；角色位置不變，鏡頭重新依保存的相對偏移定位。
- **保存目前場景設定到預置體**：把場景中的修改寫回預置體；僅可在停止播放時使用。

## 辨識方式與範圍

玩家與鏡頭依 Tag 搜尋。敵人先用 `Enemy` Tag 搜尋，再依預置體來源／保存的種類識別羊怪或花怪，避免兩種敵人混用設定。原專案中這兩種敵人的來源預置體也可辨識；新場景建議使用本資料夾已保存好的版本。

自動補齊不會每一幀覆寫數值。已存在的場景覆寫仍遵循 Unity 的 Prefab 規則；若想讓舊場景物件重新使用最新保存值，使用「將已保存設定重新套用到場景」。

`Koto → 場景設定 → 從 fight test map 保存基準預置體` 會重新從該場景擷取並覆寫這組基準；平時調整請使用上面的保存方式。`驗證預置體與自動綁定` 可檢查保存與綁定流程，報告輸出在 `Temp/SceneSetup/validation.txt`；基準數值若已修改，與原 fight test map 不同是預期結果。
