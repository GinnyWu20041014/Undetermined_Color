# 分裂小球使用方式

腳本位於 `Assets/Koto/Combat/small monster`。

已將 `Assets/animation/moster1/small/moster1 small.prefab` 設為可用的敵人預置體。直接拖入場景即可；玩家須有 Player Tag 與 PlayerHealth，地板須有 floor Tag 與 3D Collider。

- SmallMonsterAnimation：行走、召喚、攻擊、死亡動畫片段已綁定。
- SmallMonsterDetection：自動找同場景 Player Tag，也可手動指定玩家；可調偵測半徑。
- SmallMonsterCombat：預設生命 10、攻擊力 5、攻擊間隔 1.5 秒；可調受擊半徑、攻擊點、攻擊點半徑與命中動畫進度。
- EnemyAreaMovement：沿用遊蕩、追擊、地板邊界與避障功能。

根敵人死亡後原地生成兩隻 0.8；這兩隻各死亡後生成兩隻 0.5；0.5 死亡後直接移除。尺寸為根物件的固定等比縮放，不逐代相乘。子體保留母體的可調數值，血量重設為滿血。召喚期間不移動、不攻擊也不受傷，召喚結束後開始偵測與戰鬥。

不使用 EnemyStateHealth、光照顯影、實體復活或 NPC 轉換。命中與受傷使用 X/Z 距離判定，不需要實體碰撞器。地板及牆壁的移動限制仍由 EnemyAreaMovement 處理。

玩家每次成功命中只取 playerlight 的「命中敵人回復能量」（目前預設 5），致命一擊也不取得「擊敗敵人額外回復能量」。

修改場景內小球後，使用 Inspector 的 Overrides → Apply All 保存回小球預置體。這隻新敵人直接使用自己的預置體，不會套用羊怪或花怪的基準設定。

若其他場景有尚未綁定的同名物件，可執行選單 `Koto → 分裂小球 → 設定預置體與目前場景`。設定後請保存場景。

分裂生成時會優先朝左右兩側分開，並避開同場景仍存活的小球。SmallMonsterCombat 的「分裂個體間距」可調整額外保留距離（預設 0.25）。這是生成位置的分開距離；後續追擊仍沿用原本的移動方式。

動畫切換前會還原原始骨骼姿勢及材質，避免召喚動畫縮放的 body/bone_2 殘留在行走動畫，或分裂體繼承死亡動畫的消散材質。
